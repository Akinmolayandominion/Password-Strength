Password Strength Checker 🔐
About
A beginner-friendly cybersecurity project built with Python.
Features
* Checks password length.
* Checks uppercase letters.
* Checks lowercase letters.
* Checks numbers.
* Checks special characters.
* Gives a strength rating.
Technologies
* Python 3
* Regular Expressions
* Kali Linux
How to Run
python3 password_checker.py
Purpose
Created as part of my journey into cybersecurity and ethical hacking.
Educational project only. Do not enter real passwords.
